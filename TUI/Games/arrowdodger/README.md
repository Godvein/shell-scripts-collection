# ArrowDodger - Terminal Game

**Arrow Dodger** is a terminal-based arcade game built using Python and the curses library. The player controls a hero character that must dodge incoming arrows to survive as long as possible.

## Installing and Running the source code

Clone the repository:
```bash
git clone https://github.com/Godvein/shell-scripts-collection.git
cd shell-scripts-collection/TUI/Games/arrowdodger
```

**First make sure you have python installed on your linux system**

Run the python TUI game 
```bash
python game.py
```
