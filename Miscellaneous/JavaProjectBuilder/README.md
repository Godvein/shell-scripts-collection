# Bash Script to create Java Project

The script contains necessary commands to create and run Java Project helpful for programmers who prefer not to use an IDE. 

## Installation

1. Clone the repository
```bash
git clone https://github.com/Godvein/shell-scripts-collection.git
```
2. Make the file executable from anywhere
```bash
cd shell-scripts-collection/Miscellaneous/JavaProjectBuilder
chmod +x builder.sh
sudo mv builder.sh /usr/local/bin/javabuilder
```
3. Run javabuilder
```bash
javabuilder # creates java Project
javabuilder run # runs java Project
